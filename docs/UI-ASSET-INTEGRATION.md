# 游戏界面新素材接入清单 · 2026-10-03

本轮检查游戏默认入口、首页、六英雄选角、首领档案 / 三维查看、小队配置、HUD、路线 / 营地 / 结算及降级显示。角色和四区场地素材此前已完成，遗漏发生在界面的渲染分支：高清桥接原先只在战斗或暂停时启用。现在这些界面共用当前游戏 GLB，卡片和兼容模式使用从同一批 GLB 导出的静帧。

## 冷启动与加载失败补修（2026-10-04，历史基础）

用户验收发现首次打开、切换英雄和打开 Boss 三维查看时还会出现旧造型。原因是此前只覆盖了高清素材加载完成后的页面：模块导入或 GLB 下载期间仍提交旧模型；下载失败则长期保留旧模型。素材本身齐全，六名英雄与八位 Boss 的卡片已经使用新肖像。

现在首页 / 选角 / Boss 查看从第一帧使用当前素材静帧；角色与对应场地都就绪后才一起切到高清三维。切换角色必须匹配本帧对象的 key，上一位已加载的模型不会影响当前对象。模块或 GLB 失败继续显示当前静帧，PNG 也失败时显示中性展示台和双语状态。Boss 旋转 / 缩放和“实时模型”标签跟随实际就绪状态。Canvas 菜单使用同一套新素材，显式旧版对照入口继续保留。

首页新增双语首次点击音乐提示；页面中的真实点击或有效按键可启动 / 恢复音频，启动成功后收起提示。保持浏览器的有声自动播放限制，音频配方与混音未改。115/115 自动检查、真实请求暂停 / 失败与恢复、六英雄 / 八 Boss、390×844 竖屏和 844×390 窄横屏通过，见 [冷启动验收与线上复核](visual-evidence/ui-cold-start-2026-10-04/QA.md)。本补修已更新 Vercel 测试站，现已随加载升级提交到本地，未推送。

## 保留项与适用范围

- 技能符号、职业徽记、能量 / 记忆 / 故障标记、路线进度符号是功能图标；它们不代表旧角色模型，无需套用角色肖像。
- Canvas 战斗仍保留原生简化几何作为兼容渲染。高清动态战斗需要 WebGL2；本轮更新了 Canvas 的界面静帧，不将兼容渲染记作欠缺美术资产。
- 菜单的 GLB / 模块加载失败使用当前静帧；PNG 也失败时使用中性占位，卡片保留徽记。战斗仍按素材类别保留原生兼容回退。单独下载 HTML 不包含外部高清 GLB 与这些界面图片；本地完整预览使用整个工作区和静态服务器。
- `?visual=knight`、`?visual=nyx`、最早的骑士实验室与历史审图保留用于对照，不是当前游戏默认入口。全员素材图鉴 `visual-lab/roster.html` 已在使用当前模型。
- 营地 / 祭坛实体场景不适用：当前远征营地是补给菜单，没有待补接入的祭坛 GLB。
