# 音频：程序化音效与自适应配乐

**更新**：2026-10-05（同步加载版本体积；音频系统仍为 2026-10-04 的版本）。本文件说明音频系统的结构、如何改声音与曲子、混音目标和验收方法。验收记录见 [audio-evidence/2026-10-04/QA.md](audio-evidence/2026-10-04/QA.md)。

所有声音都由代码合成，本轮未引入第三方音频素材文件。`build.py` 把四个源文件按顺序拼进单文件 HTML，离线单文件版与 Vercel 高清版共用这套引擎；X Layer 参赛站需要重新发布 HTML 后才会包含新音频。音频提交 `2736882` 的单文件为 1,062,881 字节，相对 `0246c66` 增加 104,739 字节（104.739 KB / 102.284 KiB）。菜单冷启动与音乐提示补修时为 1,065,959 字节；2026-10-05 [加载体验升级](LOADING-EXPERIENCE.md) 后当前单文件为 1,087,981 字节，增加来自加载 UI 与准备控制，音频配方与媒体体积未变。

## 首次进入的音乐

浏览器对有声自动播放有用户交互要求，游戏因此在真实点击 / 按键中创建并恢复 AudioContext，而不是在下载 HTML 时播放。首页以双语提示说明“首次点击后启用音乐”；包括语言切换在内的真实点击也可启动菜单音乐，成功后提示收起。已保存的音量和静音操作仍生效。官方依据见 [Chrome Web Audio 自动播放规则](https://developer.chrome.com/blog/autoplay#web_audio)，当前页面验证见 [冷启动验收](visual-evidence/ui-cold-start-2026-10-04/QA.md)。

## 引擎结构

```
音效 ─ 增益 ─ 声像 ─┬─ 音效总线 ─────────────┐
                    ├─ 扩宽总线（全通侧声道）─┤
                    └─ 混响发送 ──┐           │
界面音 ─ … ─ 界面总线 ───────────┼───────────┤
环境（噪声床 + 点缀）─ 环境总线 ─┼───────────┤
配乐（分层增益）─ 配乐总线 ─ 闪避 ─ 低通 ─┤  ├─ 主增益 ─ 粘合压缩 ─ 限幅 ─ 输出
                         区域卷积混响 ─┘  ┘
```

- **音量设置**：「配乐」滑块控制配乐总线；「音效」滑块同时控制音效、界面、环境三条总线及其混响发送。主静音控制最终输出，也切断已在卷积器中的尾音。新存档默认配乐 24% / 音效 55%，已有存档保留原设置。
- **闪避**：大招、Boss 吼叫、Boss 陨落、进入新境等声音会按配方的 `duck` 值短暂压低配乐。
- **低通**：暂停时配乐降到 900 Hz、音量减半；主角血量低于 30% 时降到 1.7 kHz，并叠加随血量加快的心跳。
- **声部管理**：总上限 40 个声部。每个音效有自己的最短间隔 `gap` 和同名并发上限 `max`；声部满时，新声音只能挤掉优先级 `pri` 更低的旧声音。所有音效都经过声像器，队友触发的声音减半，距离超过 420 时逐渐衰减。
- **预渲染**：首次点击时创建音频上下文，随后在空闲时按 8 ms 一片渲染，顺序为界面音 → 菜单曲 → 英雄与常用战斗音 → 第一境、Boss、营地曲 → 大招与 Boss 音 → 环境。其余各境的曲子在进入该境时预热（本境 + 下一境，第三境起加终局 Boss 曲）。桌面端开场预热约 0.8 秒 CPU，菜单阶段就能完成；尚未渲染的声音会在首次使用时就地渲染。
- **内存**：音效按 32 kHz 渲染，低沉的爆炸、吼叫、心跳等用 22.05 kHz，212 个变体共 18.1 MB；乐器采样（垫音、合唱、管风琴、贝斯 22.05 kHz，其余 32 kHz，带循环点）全部 77 个根音共 15.4 MB；打击乐 2.7 MB。实际一局只加载其中用到的部分。
- **混响**：每个区域一套卷积脉冲响应：青岚 1.8 s、寒渊 2.8 s（明亮）、赤烬 1.3 s（暗、干）、冥月 3.6 s（空旷）。脉冲响应按音频上下文的实际采样率生成，44.1 / 48 kHz 都适用。
- **标签页隐藏**时挂起音频上下文；后台节流造成的配乐积压会直接跳过，不会补发。

游戏只调用这些接口（Node 测试桩只实现前五个，新接口一律用 `?.` 调用）：`init / sfx(name, pan, power, {rate, when}) / music(name) / battle(压力, Boss在场, 关卡段, 血量比, 无双中) / pause`，以及 `stage(区域) / boss(编号) / bossRage() / bossDown() / update / info`。`core.js` 里的 `sfxAt(name, x, y, power, actor)` 负责按主角位置计算声像和距离衰减。

## 声音清单

**英雄**（0 晓斌 · 天枢银剑，1 阿喵 · 金焰重剑，2 旺财 · 雷剑，3 吱吱 · 千机剑针，4 柳如烟 · 花影，5 小蓝 · 冰魄）：每位有 `shot`（普攻齐射）、`tint`（命中附色，只给玩家自己的英雄）、`skill`、`ult`、`pulse`（无双持续期间每次脉冲）。武器和招式的附加事件另有 `chain` 雷链、`drain` 花影吸取、`shatter` 碎冰、`stun` 麻痹、`freeze` 冻结、`bomb` 星爆。

**Boss**（0 赤焰魔尊 · 火，1 玄冰骨龙 · 冰，2 啸岳妖王 · 兽，3 九幽尸将 · 亡魂，4 天机巨神 · 机械，5 万魂神坛 · 灵，6 碧厄三首 · 毒，7 烬天凰皇 · 凰火）：每位有 `roar`（登场；狂暴时降调重放并叠加 `enrage`）、`volley`（弹幕发射）、`boom`（预警落地）。通用的有 `warn` / `warnlane`（圆形 / 直线预警出现）、`summon`、`charge`、`zone`、`eshot`（小怪 / 精英弹）、`bossdie`。

**通用战斗与主角**：命中按目标材质分为 `hit` / `armor` / `bosshit`，另有 `crit`、`kill` / `elitekill`、`dash`、`block`、`hurt`、`shieldhit`、`shieldbreak`、`downed`、`revive`、`heartbeat`、`levelup`、`upgrade`、`ultready`、`breakout`。拾取有 `orb`（连续拾取时音高沿五声音阶上行）、`heal`，以及 `chest`（一个声音里叠了三层奖励：剑鸣 / 上扬 / 低钟）。

**关卡与界面**：`stage`（锣 + 太鼓）、`wave`（三声战鼓）、`win` / `fail`；`ui_click` / `ui_select` / `ui_confirm` / `ui_back` / `ui_open`、`route`、`camp`、`reward`。

**环境**：每个区域有一层持续的噪声床（由滤波噪声和 LFO 调制构成，不会重复）和随机点缀：
- 青岚：雨、山风、雨滴、远钟
- 寒渊：呼啸风、冰裂、风铃
- 赤烬：低频轰鸣、余烬、远处铁砧
- 冥月：虚空低鸣、低语、风铃、远钟

旧事件名 `shot / skill / ultimate / heavy / level / pickup / boss` 仍有别名，可以继续使用。

## 配乐

| 曲目 | 用途 | 调式 / 速度 | 主奏与特色 |
| --- | --- | --- | --- |
| 青岚序 `menu` | 主菜单、选角、结算 | D 宫（B 羽）72 | 笛、合唱、古筝 |
| 篝火 `camp` | 远征路线与营地 | A 宫 66 | 古筝八分琶音、笛、木鱼 |
| 青岚古庭 `battle0` | 第一境 | G 宫（E 羽）122 | 古筝快琶音、太鼓、堂鼓、笛 |
| 寒渊雪境 `battle1` | 第二境 | E 宫（C# 羽）112 | 二胡、冰晶钟琴、慢太鼓 |
| 赤烬废城 `battle2` | 第三境 | F 宫（D 羽，弗里几亚色彩）134 | 唢呐、失真贝斯、铁砧、拍手 |
| 冥月天阙 `battle3` | 第四境 | D 宫（B 羽）126 | 管风琴、合唱、二胡、大锣 |
| 妖王 `boss` | Boss 0–6 | C 宫（A 羽）140，狂暴 +5% | 二胡、霓虹脉冲琶音、合唱 / 铜管；按 Boss 编号小幅移调 |
| 终焉 `bossfinal` | 第四境 Boss 与烬天凰皇 | 降 B 宫（G 羽）132 | 管风琴、合唱、铜管、大锣 |

每首曲子分 5 层，强度越高，越多层淡入：0 底垫 → 0.12 旋律 → 0.34 律动 → 0.54 鼓组 → 0.80 高潮。

战斗中的强度由 `battle()` 计算：基础值是 0.2 + 包围压力 × 0.78；无双中至少 0.9，血量低于 30% 至少 0.72，Boss 曲至少 0.72，Boss 狂暴时为 1。强度上升快、回落慢，避免层级来回闪烁。旋律每 24 小节里有 8 小节休止留白，主题不会一直贴在耳边。

### 写曲 / 改曲

旋律用简谱写在 `SONGS.*.tracks[kind='melody'].notes` 中，格式为 `音级[升降八度]/时值`：

- `1–7` 是调内音级，`0` 是休止；`'` 升八度，`,` 降八度；`#` / `b` 表示变音。
- 时值以十六分音符计，`/4` 为一拍，每小节必须恰好 16。
- `|` 只用于分小节，方便阅读。

和弦每小节一个，格式为音级加性质，如 `6m 4 5 3M`（`m` 小三、`M` 大三、`s` 挂四、`2` 挂二、`5` 空五度）。节奏串每小节 16 格：`X` 重音、`x` 普通、`g` 轻、`-` 延续、`.` 休止；低音里 `o` 表示高八度、`5` 表示五度。

测试会逐小节核对时值，并检查旋律循环与和弦循环对齐、音高不超出乐器音域。

## 混音目标（默认音量：配乐 0.24 / 音效 0.55）

每个音效先渲染，再按 150 ms 近似 K 加权短时响度（70 Hz 高通 + 3 kHz 提升）统一归一到 -20 dB。峰值超限时先软限幅再归一。运行时增益由类别目标 `LU` 推算，所以同类声音的响度一致。下表是增益为 1、居中时的短时响度：

| 类别 | 目标 dB | 类别 | 目标 dB |
| --- | --- | --- | --- |
| 大招 / Boss 吼叫 | -11 | 技能 | -14 |
| 升级、圣物匣、冲出重围、复活 | -15 | 受伤 | -17 |
| 预警落地 | -18 | 无双脉冲 | -20 |
| 普攻齐射、Boss 弹幕、踏风 | -22 | 普通 / 护甲命中 | -25 |
| 击杀 | -26 | 暴击、经验、小怪弹 | -27 |
| 命中附色 | -30 | 环境点缀 | -31 |

真实引擎离线计量（含环境声、混响、主链），见 QA 记录：

- 配乐：菜单 -21.3、营地 -22.5、战斗约 -27（平静）→ -22（中等）→ -20（高潮）、Boss 约 -20.5 LUFS。
- 四个区域的环境噪声床：-35 到 -36.6 LUFS，比配乐低约 8–10 dB。

## 试听与验收

```bash
npm run visual:lab
```

打开 <http://127.0.0.1:4173/visual-lab/audio-lab.html>，先点「启动音频」。也可以打开 <http://127.0.0.1:4173/Neon_Reliquary_v3.html?visual=hd> 在游戏里实际听。

```bash
npm run audio:review
```

把全部音效试听卷和八首配乐预览导出到 `art/review/audio/`。这些文件已被 git 忽略，可以随时重新生成。配乐预览由 Node 混音，不含环境声；为方便试听，统一提升到 -16 LUFS，游戏内的实际电平以上面的数值为准。

`?test` 模式下，`window.__NR.audio` 提供 `info()` / `meter()` / `requests(reset)` / `play(name)` / `recipes()`，可以只读地检查哪些音效被游戏请求过，不影响战斗。
