# 誓约远征 · 完整首版

2026-09-23。用户确认按完整游戏推进，本文件是本次实现与验收的范围依据。游戏原型、素材及既有协作修复来自本目录；参赛是交付用途之一，不能以最小演示代替完整首版。

## 产品与玩法

四人协作 Roguelite。主角在人类和外部 AI 间选择，三个队友各自在外部 AI 或战术芯片间选择。保留六职业、已有程序化三维模型、即时战斗和双语。普通玩家可以直接免费游玩，无需钱包、模型账号或电路知识。

一局远征依次经历组队、路线选择、遭遇、奖励/营地、首领与结算。完整路线包含清路、护送、守点、救援、首领合击等合作要求；局内升级和临时增益形成构筑，局外研究、底座解锁、蓝图与队伍方案保存支撑下一局。挑战契约提高取舍与奖励，不能只增加敌方秒杀伤害。

芯片决定行动优先级、技能时机、后续升级和有限记忆。引擎执行移动、基础攻击、冷却、碰撞和合法性；合法的芯片选择不能被旧机器人高层规则暗中覆盖。AI 使用同样的行动权限，控制来源和超时接管必须清楚。

每个角色两件圣物，共享能量。六种底座覆盖护盾、治疗、击退、强化、冻结和蓄能支援；效果和预算由游戏规定，电路决定条件与事件记忆。救援不能刷出无限能量；技能请求只有真正成功才反馈消费，暂停不推进状态，新局重置，战中禁止换装重置预算。

## 工坊与制造

提供模板使用、优先级/条件编辑、有限记忆、说明和真实网表/BLIF 导出。蓝图可免费试验；固定条件的战术实验室比较版本并显示真实指标，明确它是局部场景而非整局可信链上回放。

制作流程：编辑 → 编译/检查 → 试验 → 核对最终材料及费用 → 用户钱包确认 X Layer 流片 → 从链读取与校验 → 装备。官网仍可作为导入检查入口。制造后的逻辑固定，更改产生新的版本，保存父版本与说明。共享包可以导入、试用、改编，展示本地/公开链上来源。

使用扁平 NAND/LATCH，不依赖 X Layer 尚不支持的 REF 流片。输入输出 ABI 及阈值绑定版本。链上制造、本地战斗求值；LATCH 对局状态由游戏管理，不冒充 view 调用已持久保存链上记忆。

X Layer 适配器必须校验网络、工厂登记、网表限制和固定接口，拒绝不兼容或畸形内容。完整制造 UI 可以实现，但真实部署、付费、供应量和单价需要用户对具体参数及费用授权。开发测试不发送主网交易，不从其他项目挪用付款授权。

## 初版内容基准

- 六职业、四位置混编、人类/外部 AI 队长。
- 完整多区域远征、分岔路线、营地、最终首领、胜败结算；保留原有征途/无尽/首领挑战供选择。
- 队友可改模板与有限记忆；技能、升级和行动实际由电路输出驱动。
- 六圣物底座、每角色两个槽、共享能量与冷却、事件反馈。
- 编辑/试验/版本/导入导出/制造/读回/安装组成完整工坊。
- 局外解锁、队伍保存、蓝图分享与父版本记录。
- 真实 Agent 入口、控制权切换与失联提示；不把规则机器人称为外部 LLM。
- 双语、键盘与触屏布局、离线基础游玩、明确异常与损坏存档处理。

## 验收

逻辑：编译与网表求值一致，记忆生命周期，畸形输入与包拒绝，控制权隔离，升级幂等，圣物资源/回执、路线营地胜败、解锁和持久化。

战斗：固定条件的多种子实验覆盖六职业、混编、救援/驻守/护送/首领；新机制不得破坏已修复救援，不能用清敌/无敌测试替代实战可玩性。

真实界面：主线程用浏览器完整跑新手开局、工坊编辑与试验、版本分享往返、换装保存、远征路线/营地/结算、AI 队长接入与人工接管；检查双语与窄屏。最后独立复核发现问题后修复并重测。

交付：可运行单文件与本地服务、独立 Git 仓库和功能检查点、更新使用与 Agent 文档、当次测试和浏览器验收报告。对主网未执行步骤和没有测过的平台明确注明，不以此提前结束已授权的本地实现。
