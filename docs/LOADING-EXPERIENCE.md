# 资源加载与转场体验 · 2026-10-05

首页、选角、Boss 查看、首次战斗和跨区域转场已接入加载反馈。先保留同一批新模型导出的静帧，再显示真正完成首帧绘制的三维画面。下载、模型准备、首帧绘制分别计状态；不使用模拟百分比。

| 位置 | 反馈与行为 |
| --- | --- |
| 首次打开 | 启动符文先绘制，等待当前首页静帧；图片最多等待 1.5 秒，其余资源继续后台准备 |
| 首页 / 选角 | 当前角色和区域静帧上显示局部符文、下载量或准备阶段；不阻止选择、设置等操作 |
| 首领档案卡片 | 肖像加载时显示淡呼吸占位，图片就绪后淡入；失败保留徽记 |
| Boss 三维查看 | 保留当前 Boss 静帧；真正绘制首帧后才启用旋转、缩放与实时标签 |
| 首次部署骑士 / 进入远征遭遇 | 区域静帧与全屏符文遮罩，暂停模拟；只等待本次首帧实际需要的角色、武器、场地、敌人及拾取物 |
| 跨区域 | 未准备好时显示同样的区域转场；已经缓存的资源完成首帧后直接继续 |
| 近期资源 | 当前画面稳定 800 毫秒后低优先预载下一位英雄 / Boss；战斗中预载下一首领及邻近区域 |

局部提示延迟 150 毫秒出现，避免快速命中缓存时闪一下；文本最多每 200 毫秒更新。静帧在三维首帧之后用 280 毫秒淡出。符文采用 CSS 的透明度与变换动画，颜色跟随四区；系统选择减少动态效果时禁用旋转、呼吸、扫光及淡入。竖屏选角采用紧凑提示，给小队按钮保留空间。

共享下载队列最多并行三份资源，模型解析与准备串行执行，当前选择提升优先级。下载结束后仍需解析、材质 / 辉光着色器预编译和首帧绘制；压缩响应或未知长度的响应只显示不定进度，下载完成才获得准确字节数。实例动画预烘焙分段让出主线程，肖像裁切使用预生成边界，近期菜单模型实例最多保留四个。现有 GLB / PNG 未重制，未增加音频媒体。

关键资源失败立即显示重试，不等待其他下载完成。资源请求含准备阶段的超时为 90 秒，高清模块初始化超过 45 秒则显示失败状态。菜单失败保留当前静帧；战斗失败提供重试、兼容画面继续、返回选角。加载等待期间时间、移动、伤害和技能冷却都不推进，成功或明确选择继续后重置模拟累积时间，避免补算等待期间的战斗。返回菜单、选角或结算会清除等待；过期下载 / 准备结果不能覆盖重试后的对象。高清模块或渲染器初始化失败的重试刷新页面。

Canvas 菜单仍显示当前静帧，Canvas 战斗保留原生兼容渲染，不等待外部高清资源。暂停菜单在加载期间仍可使用。音频保留真实首次交互解锁机制，加载完成不代表浏览器已允许有声播放。

本地、自动检查和上线证据见 [验收记录](visual-evidence/loading-experience-2026-10-05/QA.md)。本轮基于 `ebeb157` 已按用户要求 commit 到本地，未 push；同一产品源码已更新独立 Vercel 测试项目，部署清单保留发布时 dirty=true 的历史状态。原 X Layer 参赛版未更新，后续托管能力仍优先考虑 CF。

GLTF 解析的同步部分、第一次纹理上传和驱动准备仍可能产生短帧停顿。本轮改善等待反馈并提前准备资源，不把截图、一次首帧样本或既有 GPU 报告当作“所有设备零卡顿”的证明；Safari / 手机真机仍待验收。
