# Neon Reliquary runtime assets

The versioned runtime asset package contains the Nandverse project's game models
and interface images integrated from the visual development repository at
`5d1b6e94ba1e4a967b47314c925b724e4f4ab69d`. Its exact 60-file inventory and
SHA-256 checksums are published in `asset-manifest.json`.

These assets are distributed with Neon Reliquary for loading and playing the
game, including the public DeWeb release and the project's Cloudflare CDN.
Project-specific artwork remains reserved to the project; this notice does not
grant a separate general-purpose asset-pack license, claim exclusive copyright
in AI output, or relicense the original uploaded game.

The new models are built by the project's Blender recipes. Interface portraits
and backdrops are the project's existing generated artwork. No downloaded
third-party model or commercial music pack is included. Sound and music are
synthesized by the game program rather than distributed as audio media.

game's author and source attribution is preserved in the repository's README
and author provenance documentation.
